## 3. Выводы по результатам поблочного сравнения

1. **Реальные расхождения, требующие доработки по ТЗ:**
   - **Пункт 1:** Длинные запросы (снятие ограничения 120 символов и приведение лимита к `maxlength="200"`).
   - **Пункт 2:** Традиционные составные слова (`學習` -> `学习`, `電腦` -> `电脑`, `繁體字` -> `繁体字`).
   - **Пункт 3:** Поиск пиньиня без тонов (`xuexi`): вывод полной таблицы омофонов из `pinyin_map.json` с постраничным лимитом и кнопкой «Показать ещё».

2. **Осознанные расхождения (оставляем без изменений):**
   - **Поиск с тонами (`xuéxí`, `xue2xi2` и т.д.):** bkrs.info не умеет искать с тонами и возвращает ошибку; наш движок корректно поддерживает тональный ввод.
   - **Спецсимволы (`^`, `*`, `~`, `$`, `/`):** сохраняем наш расширенный синтаксис поисковых операторов.
