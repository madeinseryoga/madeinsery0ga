# Сверка возможностей поиска БКРС с bkrs.info

Таблица возможностей поискового интерфейса и движка БКРС.
Колонка **«Как на bkrs.info»** заполнена по результатам реального исследования и браузерного рендеринга страниц сайта [bkrs.info](https://bkrs.info).
Колонки **«Есть у нас»** (`да` / `нет` / `хуже`) и **«Где в коде»** (функция и номер строки) заполнены по исходному коду `index.html`.
