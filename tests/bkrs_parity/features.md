# Сверка возможностей поиска БКРС с bkrs.info

Таблица возможностей поискового интерфейса и движка БКРС.
Колонку **«Как на bkrs.info»** заполняет человек при ручной сверке с живым сайтом [bkrs.info](https://bkrs.info).
Колонки **«Есть у нас»** (`да` / `нет` / `хуже`) и **«Где в коде»** (функция и номер строки) заполнены по результатам аудита исходного кода `index.html`.
