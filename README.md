# 🇨🇳 Платформа изучения китайского языка (Chinese Learning & Text Study)

Интерактивное веб-приложение (Single Page Application) для всестороннего изучения китайского языка, подготовки к HSK, разбора китайских текстов и генерации учебных материалов.

---

## 🌟 Ключевые возможности

1. **Анализатор текстов (Text Study):**
   - Умное сегментирование китайского текста на слова.
   - Кликабельные слова со словарной статьей БКРС, пиньинем, разбором по иероглифам (черты, ключи Канси) и примерами из текста.
   - Модальное окно экспорта словаря: выбор всех слов или отметка конкретных слов чекбоксами.
   - Экспорт для **Quizlet** (2 режима: с пиньинем и без пиньиня).
   - Экспорт для **Anki** (TSV-карточки).
   - Экспорт для мобильного приложения **MyDictionary Polyglot** (100% совместимый `.xls` со списком примеров и тегами).

2. **Прописи и рабочие тетради (Copybooks Generator):**
   - Настраиваемая разлиновка: 田字格 (квадраты с крестом), 米字格 (квадраты со снежинкой).
   - Генерация макетов прописей для печати на А4 с порядком черт и образцами написания.

3. **База HSK (1–6 уровни):**
   - Списки лексики по уровням HSK.
   - Карточки для запоминания и интерактивное тестирование.

4. **Офлайн-словарь БКРС:**
   - Быстрый поиск по иероглифам, пиньиню и русскому переводу.
   - 100 локальных JSON-шардов без необходимости подключения к сторонним серверам.

5. **Ключи Канси (214 радикалов):**
   - Полная интерактивная таблица всех 214 ключей с этимологией, примерами и вариантами написания.

6. **Тренажеры и обучающие игры:**
   - Практика тонов, аудирования, распознавания иероглифов и грамматики.

---

## 🚀 Запуск и использование

- **Онлайн:** сайт опубликован через GitHub Pages. При входе запросит пароль доступа.
- **Локально (с компьютера или флешки):**
  - Просто откройте файл `index.html` в любом современном браузере (Chrome, Edge, Firefox, Safari).
  - Введите пароль для доступа к платформе.
  - Никакой веб-сервер, Node.js или базы данных для работы пользователя не требуются — всё работает прямо в браузере.
